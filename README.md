Entry for make.fun's **"Real-Life Patch Notes: The Comedy Changelog"** bounty ($5 in USDC).

The entry is one line in `entry.txt` — a software patch note for a bug in real life, at most 160 characters, written in the terse register of a real release note.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) copies the committed `entry.txt` into `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`), which is what the harness reads.
